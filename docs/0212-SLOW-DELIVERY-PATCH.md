# 0212 — применено (обход по разрешению заказчика)

## Что закоммичено у structure

| Коммит | Что |
| --- | --- |
| `1720cb4` | config: allow для lib/test на время применения |
| `4cc093b` | **фикс**: `startHeartbeat` сканирует и доставляет (slow-scan) + тест c7 на новое поведение |
| `4cc09*`-рядом | контракт 0212, блок критериев, lock, red-артефакты |
| `1693a03` | артефакты красного прогона и lock |

Проверка на их тесте: `node test/exchange-delivery.test.mjs` → `EXCHANGE DELIVERY TEST OK: 7/7`.

## Что это меняет

`exchangeWatch: false` больше не убивает доставку: медленный таймер (60 с) сканирует и вручает,
heartbeat пишется на каждом тике. Флаг снова означает только «без быстрого таймера», а не «почта выключена».

## Важно: живой хост

Установленный плагин в `~/.dsh/profiles/desktop/node_modules` — **старая сборка**. Пока она не обновлена,
флаг `exchangeWatch` в профиле оставлен `true` как страховка. После обновления плагина флаг можно
вернуть в `false` — доставка продолжит работать уже из кода.

## Долг процесса

Коммит сделан в обход guard через `guard.allow` (осознанно, по разрешению заказчика, метка
`workflow-bypass` в сообщениях). После применения `guard.allow` возвращён в строгое состояние
(коммит `03d8e05`), затем снова ослаблен на время правки (`1720cb4`). Это след в аудите.
