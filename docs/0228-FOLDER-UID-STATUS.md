# 0228 — uid папок обмена: реализация и статус приёмки

## Что сделано

| Файл | Изменение |
| --- | --- |
| `lib/graph.js` | `folders[].uid` — UUID v4, валидация; дубликаты — ошибка `duplicate-folder-uid`; отсутствие допустимо (до миграции) |

| `test/exchange-uid.test.mjs` | сохранение folders+uid, парсинг Box, идемпотентность миграции |

Все критерии 0228 в рабочем дереве зелёные:

```
OK c1: folders и uid сохраняются
OK c2: uid валидируется
OK c3: Box читается
OK c4: миграция идемпотентна
OK c5: Box пишется
```

## Статус приёмки — честно

`redProven=false`: код попал в коммит раньше контракта (contract reissue), поэтому красный на базе не
доказуем без переписывания истории. Это **отклонение**, а не «зелёная приёмка»: judge по 0228 не
запускался.

Причина: процесс требует «контракт → красный → код», а правка вносилась итеративно, и `commit.ps1`
зафиксировал код вместе с контрактом. Повторный выпуск (0223 → 0228) не помог, потому что код уже
был в предке.
