## Цель

Два замечания из практики, оба про то, что движок молчит или говорит не то:

1. **WC-47 (наш).** 0061 научил ворота подсказке при сдвиге HEAD, но текст один на все случаи:
   «не коммитьте критерии и артефакты». Сторонний оркестратор (0023) собирался закоммитить
   **код** перед приёмкой — и получил бы подсказку про артефакты, то есть неверный диагноз:
   у нас код не коммитит никто, кандидата создаёт `task-accept`, ветку двигает архитектор.
2. **WC-45 (вопрос structure, `--145` §4).** `doctor` валит ключ `stable` (kind `agent` без
   префикса), которым подписаны 8 исторических приёмок. Переименовать нельзя — записи перестанут
   резолвиться. Отзыв (`revokedAt`) в движке уже поддержан, но правило имени смотрит весь список.

## Что не входит

1. Алиасы ключей (`aliasOf`) и переименование закреплённых ключей — не делаем.
2. Ослабление проверки для активных пинов: ключ без префикса у активного пина по-прежнему FAIL.
3. Изменение `verifyLock` как чистой функции: причину сдвига определяют вызывающие.

## Инварианты

1. **Подсказка различает причину.** При сдвиге HEAD (`lock: contractCommit: ожидалось X, сейчас Y`)
   `task-red` и `task-verify` печатают подсказку, которая:
   (a) перечисляет три причины сдвига — **артефакт** задания (`criteria.lock`, `red.json`), **код**
   исполнителя, **metadata** приёмки;
   (b) называет правило: артефакты не коммитятся до приёмки; код не коммитится — кандидата создаёт
   `task-accept`, ветку двигает архитектор после metadata; metadata принятого задания — ожидаемый
   сдвиг;
   (c) печатает фактически изменённые пути `git diff --name-only <contractCommit> HEAD`, чтобы агент
   увидел свою причину;
   (d) в сценарии «закоммичен код» вывод содержит слова «код» и «task-accept», в сценарии
   «закоммичен артефакт» — «артефакт» и «кандидат».
2. **`lockOrderHint` остаётся чистой.** Она принимает `lockCheck` и необязательный список
   изменённых путей; решение «это сдвиг» по-прежнему только по ошибке `contractCommit:`.
3. **doctor: имя ключа — только у активных пинов.** Фильтр `bad` учитывает только записи без
   `revokedAt`; отозванный legacy-ключ без префикса — документированное исключение (история),
   активный ключ без префикса — по-прежнему FAIL с именем ключа.
4. **Регресс.** `gate-diagnostics.mjs c1` (подсказка при артефактном сдвиге) зелёный;
   `pipe-free.mjs c1` — новые спавны без пайпов; `selftest` и `gate-rules` зелёные.
5. Непонятно — стоп и один вопрос. Догадываться запрещено.
