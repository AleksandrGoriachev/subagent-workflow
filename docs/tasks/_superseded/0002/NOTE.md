# 0002 аннулировано

Причина: приёмочная проверка `spec/checks/guard-acceptance.mjs`, кейс `panel`, использовала
`import()` с абсолютным путём. На Windows Node отвергает такой импорт
(`ERR_UNSUPPORTED_ESM_URL_SCHEME`: нужен `file://`), поэтому критерий C6 не мог стать
зелёным независимо от реализации.

Дефект постановщика (проверку писал архитектор), а не исполнителя. Правило I-3 запрещает
перезамок после красного с другим содержимым контракта, поэтому выпущено задание **0003**
с исправленной проверкой (`import(pathToFileURL(...).href)`).

Файлы замка и красного прогона оставлены здесь как история.
