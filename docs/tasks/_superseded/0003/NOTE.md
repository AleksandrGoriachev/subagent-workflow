# 0003 не подписано

Приёмщик отказал по существу, хотя формальные ворота были зелёными:

- **P1.** pre-push применял правило покрытия к уже сделанным коммитам по ТЕКУЩЕМУ состоянию:
  коммит, сделанный при открытом задании, после появления acceptance.json становился
  «не покрыт», и пуш отклонялся — блокировался предписанный порядок «приёмка → пуш».
- **P2.** Метка [workflow-bypass] разрешала коммит, но не пуш: --range передавал пустое сообщение.

Дефект в недостаточности приёмочных проверок (C1–C8 не проверяли пуш), то есть работа
постановщика, а не исполнителя. I-3 запрещает перезамок после красного с другим содержимым,
поэтому выпущено задание 0004 с кейсами pushAfterAcceptance и bypassOnPush.
