# 0209 — Якоря глобальные, gates у узла, approval enforced

## Зачем

Модель заказчика: **якоря пишутся для всей структуры, а к узлу применяются гейты**.
Сейчас A8 обещает «ревьюер без consumes — отказ», а `role-policy.js:143–60` раздаёт «все auto»;
`structure/approval.json` отсутствует, `verifyStructureApproval` в рантайме не вызывается.

## Что сделать

1. `anchors.consumes` у узла удалить; legacy-графы читать с предупреждением.
2. Ввести `lib/gates.js`: `GATES = { id: {phase, appliesTo, run} }`, `gateIds()`, `runGates()`, `missingGates()`;
   документ `docs/GATES.md`. Обязательные id: `review-receipt`, `anchor-binding`, `preset`, `release-receipt`, `accept-line`.
3. Пустые `gates` у reviewer/аудитор/judge/релизной роли — **отказ активации**.
4. A8 переписать по `A8-NEW-WORDING.md` (утверждён владельцем); подпись ставит владелец после миграции.
5. `verifyStructureApproval` — в рантайме: запись структуры (`lib/api.js`) и активация (`lib/spawn.js`).
6. `role-policy.js` — только модель/промпт; `all-auto`/`defaultConsumes` удалить.
7. 0186/0192 заменить (глобальные якоря + гейты), не «поправить».
8. Реестр: фантомные `open` → `cancelled` со ссылкой «→ NNNN».

## Критерии

Внешний чек: `spec/checks/stopline/t3-policy-truth.mjs` (9 проверок), включая approval в рантайме и актуальную подпись.

## Не входит

UI-редактор гейтов; переписывание всех проверок якорей глубже 0186/0192.
