# 0208 — Граф без потерь + активация в своём воркспейсе

## Зачем

`buildStructure` (api.js:2327–48) перезаписывает граф whitelist-объектом и теряет `prompt`, `anchors`,
координаты, расписание, привязки сессий. Позиции/папки панели живут в том же `graph.json` (54 коммита,
26 ручных; `e60547c` «вернуть folder-5»). Активация создаёт сессию в `Temp\dsh-spawn-*` — падение координатора.

## Что сделать (fail-closed первым коммитом)

1. `buildStructure` сохраняет неизвестные поля **или отказывается** перезаписывать файл.
2. Состояние панели (позиции/папки/привязки) — отдельный файл (`structure/state.json`), не конфиг.
3. `add/updateNode` не откатывают чужие новые байты: CAS по rev/hash.
4. Активация отклоняет сессию, созданную не в воркспейсе узла, с понятной причиной.

## Критерии

Внешний чек: `spec/checks/stopline/t2-graph-noloss.mjs` (3 проверки). Плюс свой тест:
пересборка сохранила `prompt/anchors/x/y/schedule/session`; два параллельных update не теряют рёбра.

## Не входит

Полный рефакторинг `api.js` (7 726 строк) — это P2, отдельной задачей.
