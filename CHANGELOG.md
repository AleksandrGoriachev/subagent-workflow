# Изменения

## 2.0.2 — 2026-10-25

- `init` больше не копирует `acceptors.json`: при развёртывании из уже
  инициализированного каталога он видел закреплённый ключ, пропускал генерацию,
  и новый workspace оставался без приватного ключа (e2e падал на приёмке).
- Скан секретов читает полный текст только неотслеживаемых файлов; изменённые
  файлы дают лишь строки диффа. Убраны ложные срабатывания на предсуществующих
  строках (перенесено из 1.4.2 проекта-источника).

## 2.0.1 — 2026-10-25

Подтянуто правило 1.4.1 из проекта-источника: разбор замечаний приёмщика.

- `review.json`: классификация `blocking` / `non-blocking` / `follow-up`.
- `task-accept --review`: `rework` и `blocking` без `resolution` не принимаются.
- В записи появились `review` и `releaseReady`; `task-check-acceptance` сверяет их.
- `releaseReady=false` означает: приёмка есть, выкатывать нельзя.

## 2.0.0 — 2026-10-25

Переносимая редакция: один пакет, который разворачивается в любом репозитории.

- **Все ворота в пакете:** `hash`, `lint`, `red`, `verify`, `accept`, `check` —
  исполняемые, с самопроверкой.
- **Аттестация актора:** сессия из окружения, запрет совпадения с `issuedBy` и
  `executorSession`, уровни `declared` / `separate-session` / `human`.
- **Ed25519:** публичные ключи в `acceptors.json`, приватные вне репозитория;
  HMAC для новых записей не используется.
- **Запись версии 4:** `actor`, `issuedBy`, `independence`, свежий прогон,
  `redExpectation`, подпись.
- **Загрузчик пространства:** `init` (структура, ключ, конфигурация, .gitignore) и
  `new-task` (шаблоны с `issuedBy`).
- **Диагностика:** `doctor` и `actor --check` для проверки пригодности харнесса.
- **Адаптеры:** DSH, произвольный раннер, CI.
- **Сквозная проверка:** `e2e` проходит цикл на временном репозитории, включая
  отказ самоприёмке.
- **Упаковка:** `tools/pack.mjs` собирает zip с manifest и контрольными суммами.
